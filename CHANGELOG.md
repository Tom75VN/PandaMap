# Changelog

Player-visible PandaMap changes, newest first. Keep every bullet short, clear and focused on what changes for the player.

## [Unreleased]

## [1.0.1] - 2026-10-30

### Changed

- Map packs install separately, so core updates no longer redownload unchanged artwork.

### Fixed

- Without PandaUI, the minimap and World Map show the player arrow again.

### Removed

- Opening the World Map no longer shows the misplaced player ping.

## [1.0.0] - 2026-10-28

### Added

- The Panda Map settings header now shows the version and an accent-colored "Map", like the other Panda addons.
- Drag the resize icon in the minimized world map's bottom-right corner to resize it; the size is remembered.

### Fixed

- Zooming the minimized world map no longer snaps back to its original zoom.
