# PandaMap UI textures

- `mousewheel-zoom.tga`: World Map "Zoom" hint drawn by `MapZoom.lua` when
  pandaUI is not installed. Copied unchanged from pandaUI
  (`media/Textures/mousewheel-zoom.tga`, see pandaUI's
  `media/Textures/ATTRIBUTION.md`): supplied by the pandaUI author on
  2026-10-20, generated with ChatGPT's image model from a prompt written for
  that addon, converted to a 64x64 uncompressed 32-bit TGA.
- `resize.tga`: minimized World Map resize grip drawn by `MapZoom.lua`.
  Copied unchanged from pandaUI (`media/resize.tga`, its chat and bag resize
  grip), a 32x32 uncompressed 32-bit TGA.
- `player-arrow-frames.tga`: player arrow drawn on the minimap and World Map
  by `PlayerArrow.lua` when pandaUI's arrow is not running. Copied unchanged
  from pandaUI (`media/Textures/modern-wow/minimap/uiminimap-player-arrow-frames.tga`,
  see pandaUI's `media/Textures/modern-wow/ATTRIBUTION.md`): 64 pre-rotated
  cells of Blizzard Retail's `UI-HUD-Minimap-Arrow-Player`, 512x512 TGA.
